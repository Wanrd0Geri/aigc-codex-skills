# Controlled Image-Edit Shapes

Load this file only when an edit needs auditable blocks. Surgical edits use the direct 1-3 sentence contract in `SKILL.md` and `mode-edit.md` without loading this reference.

## Controlled edit

Use when several linked changes form one repair, or when identity, geometry, layout, brand, or text needs explicit protection.

```text
修改：
- [位置 + 变化 + 可见终态]
- [仅限同一修复系统中的第二项变化]

保留：
- [本轮最重要的身份、几何、构图、文字或品牌锁]
- 其余未提及内容不变。
```

```text
Change:
- [location + change + visible endpoint]
- [a second change only when it belongs to the same repair system]

Keep:
- [the critical identity, geometry, composition, text, or brand locks]
- Keep every other unmentioned element unchanged.
```

Add one direct exclusion only when a concrete likely drift cannot be prevented by the positive change and keep lines.

## Multi-reference, typography, or layout edit

Use only the blocks the task actually needs:

```text
参考图职责：
- 图1：仅控制[身份/姿势/构图/服装/物体/环境/风格轴]
- 图2：仅控制[另一项已分配属性]

修改：
- [把谁的什么内容放到哪里，以及必要的比例、透视、遮挡或光线匹配]

严格保留：
- [底图的关键锁]

画面文字：
- 原样显示“[精确文案]”，位于[位置]，采用[必要的字体视觉特征]。
```

Use an English semantic mirror in its own fenced block. Preserve exact visible copy in its original language unless translation is requested.

## Optional integration clauses

Choose only the fields needed for changed pixels to belong in the image:

- source scale, perspective, occlusion, or contact point
- light direction, shadow softness, color temperature, or material response
- original medium when an edit could accidentally convert animation, illustration, or stylized 3D into live action

For visible broken edges, noisy microtexture, brush buildup, or patchwork rendering, one compact cleanup directive is enough. Do not add a texture blacklist, quality-booster tail, or unrelated camera jargon.

Never print an empty block or restate the same protection positively and negatively.
