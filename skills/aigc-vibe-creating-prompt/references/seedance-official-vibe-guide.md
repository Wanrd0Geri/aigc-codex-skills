# Seedance Official Vibe Guide

This reference is distilled from the user's official Seedance Vibe Creating guide. Load it only when the user explicitly asks for official Vibe guidance, asks why Vibe works, wants A/B calibration, or the normal Vibe output needs style correction.

## Core Model Preference

Seedance Vibe Creating works best when the prompt helps the model understand:

- the image center: what the viewer should notice first
- the emotional direction: what feeling or state the clip is moving toward
- the key imagery: concrete objects, bodies, spaces, light, and motion
- experiential continuity: why the visual moments belong together

The guide favors natural scene writing over mechanical parameter lists. Low-value technical controls should be softened or translated into viewer-facing visual results unless the user explicitly asks to preserve them.

## Three-Step Use

1. Judge whether the scene is suitable for Vibe Creating.
2. Choose the smallest useful action: direct pass, light refinement, rewrite, ask first, preserve as-is, or optional VC version.
3. If information is missing, ask only for the minimum details needed to complete the current action.

## Fit Matrix

### S1 Native Fit

Use direct rewrite, light refinement, or direct pass for scenes driven by story, emotion, memory, atmosphere, imagery, or a unified subjective experience. Precise control language can still be translated if the underlying scene goal is expressive.

### S2 Partial Fit

Use light refinement or optional VC version for product display, brand presentation, character display, style ads, or mixed creative/execution prompts. Preserve the user's business or display intent before adding mood.

### S3 Low Fit

Preserve as-is or lightly clean functional demos, UI tutorials, industrial procedures, strict execution plans, and long dialogue-sync scenes. Do not force atmosphere onto tasks whose value is procedural accuracy.

## Information Density

Do not rewrite when the input lacks the minimum visible basis. Check for:

- visual anchor: person, object, named concept, or effect body
- action or state: what is happening now
- local tone: one clear feeling or atmosphere
- video theme: short film, micro narrative, emotional expression, concept clip, educational visualization, VFX fragment, etc.

For short abstract inputs, ask for the missing anchor or action before inventing a scene.

## Writing Preferences

- Prefer complete natural Chinese sentences with visible subjects, verbs, and relationships.
- Keep the prompt close to the user's original size unless the user asks for expansion.
- Preserve event order and the emotional flow in multi-shot or multi-moment inputs.
- Translate abstract taste words into visible carriers: gaze, pause, posture, contact, light, spacing, movement, environment reaction, or sound.
- Preserve exact dialogue, narration, music, sound effects, asset anchors, duration, shot order, and required structure.

## What Not To Do

- Do not rewrite every prompt into poetic or memory-like prose.
- Do not invent backstory, character relationships, symbolism, or plot turns that the user did not provide.
- Do not erase technical constraints the user explicitly asked to keep.
- Do not make VC replace final Seedance execution when the task needs reference mapping, video edit, extension, lip sync, or strict continuity.
