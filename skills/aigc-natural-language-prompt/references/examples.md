# Natural-Language Prompt Examples

Use these examples only for calibration, teaching, or unfamiliar output shapes. Do not load examples for every routine rewrite.

## Single-Shot Parameter Stack

**Source**

```text
中景，女孩，雨夜街口，孤独，冷色调，电影感，高质量。
```

**Rewrite**

```text
中景固定拍摄雨夜街口，女孩独自站在画面偏左的冷白路灯下，低头看着脚边积水里的倒影。远处店铺灯光被雨水拉成长线，街道空旷，只剩雨滴落在地面上的声音。
```

## Off-Screen Cause

**Source**

```text
风从山门方向吹来，带动少年额前的碎发。
```

**Rewrite when the source is not visible**

```text
少年半边脸和肩线保持清晰，背景已经虚化。额前碎发被轻轻吹开，衣领边缘也跟着颤动。
```

**Rewrite when the source is established**

```text
山门仍在少年身后的远处虚化可见，画面深处的风带动他额前碎发，衣领边缘随之颤动。
```

## Seedance-Style Multi-Shot

**Source**

```text
镜头1：中景，古风少年，宿命感，电影感，准备拔剑。
```

**Rewrite**

```text
镜头1：4秒，中景。固定机位从石阶正前方拍摄，少年站在画面中央偏后的位置，右手垂在剑柄旁边但还没有握紧。他先低头看向脚边的积水，随后慢慢抬眼看向前方，手指在最后一秒收紧到剑柄上。
```

## Multi-Character Fox Scene

**Source**

```text
四只小狐狸在古风木屋里嬉闹，灵动热闹，Unreal Engine cinematic quality，高级游戏过场动画。
```

**Rewrite**

```text
15秒视频，古风木屋室内，四只小狐狸分别参考@图2、@图3、@图4、@图5，木屋结构和陈设参考@图1。全片为精致三维角色动画风格，非写实摄影；无旁白、无字幕，只保留脚步声、陶碗轻响、衣料摩擦声和木屋环境音。

镜头1：4秒，中景。固定机位从木屋门口内侧拍摄，桌子位于画面中央，长凳横在桌子前方，窗格光落在石地和桌沿上。@图2的小狐狸站在桌子左侧，双手扶着桌沿看向其他三只；@图3的小狐狸背着小布袋从长凳旁跑过；@图4的小狐狸踮脚看向桌上的小碗；@图5的小狐狸先在桌子右后侧露出耳朵，随后从桌角后探出半张脸。这个镜头先建立四只小狐狸在同一个房间里的位置和互相注意的关系。

镜头2：4秒，近景。镜头贴在长凳边缘的低处固定拍摄，只保留桌脚、长凳腿和小狐狸经过前景的脚步。@图3的小狐狸从画面左侧冲入，抱起一只小木勺转身跑向画面右侧；@图2的小狐狸紧跟着从左侧追进来，手伸向木勺，耳朵竖起，尾巴在急停时甩出轻微延迟。木勺碰到桌脚发出一声轻响，两只小狐狸一前一后离开画面。

镜头3：4秒，中景。镜头顺着上一镜向右的运动来到桌子另一侧。@图3的小狐狸绕过桌角急停，木勺从怀里滑落，在石地上转向桌后；@图5的小狐狸从桌角后跳出来，用尾巴把木勺轻轻挡回画面中央。@图2的小狐狸从后方追到，@图4的小狐狸一手扶住晃动的小碗，一手伸向滚来的木勺。

镜头4：3秒，低机位近景。木勺转到画面中央，四只小狐狸分别从桌子两侧、桌下和长凳后探身围住它，先同时停住，随后一起伸手。木勺被碰得再次滚向木屋深处，四只小狐狸立刻转身追出画面，只留下逐渐远去的脚步声和陶碗轻响。
```

## Image-Edit Prompt

**Source**

```text
增强电影感，提升光影，氛围更高级，不要 AI 感。
```

**Rewrite**

```text
[Preserve]
保留人物的脸、服装、姿势、道具、构图和人物数量，不改变身份特征。

[Transform]
把原本平直的正面光改为画面左侧的柔和主光，让人物右侧脸颊进入更深的阴影。背景整体压暗，保留少量冷色环境光，使人物轮廓从暗部中分离出来。降低背景雾气的均匀亮度，让前景清晰、中景轻微遮罩、远景逐渐隐入暗部。

[Avoid]
不要重绘面部，不要增加新人物或新道具，不要使用强烈神光柱、塑料皮肤、过饱和色彩或均匀雾墙。
```
