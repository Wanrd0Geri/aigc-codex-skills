# AIGC Codex Skills

这是一套按实际创作交付物组织的个人 AIGC Skills，包含图像、视频、战斗特效设计、项目上下文和提示词改写五个互补入口。Agent 会根据用户真正需要的交付物选择工作流，保护素材事实和生产约束，并在关键创作判断不确定时主动讨论。

## 五个 Skills

| Skill | 它负责什么 | 典型说法 |
|---|---|---|
| `aigc-image` | 从文字 brief 编写图像提示词，或完成画面诊断、参考图反推、图像编辑提示词和诊断后修图 | “给 Nano Banana 写人物海报提示词” |
| `aigc-video` | 编写 Seedance、豆包、Dreamina 系列或明确要求的平台中立最终视频提示词，覆盖生成、编辑、延长、桥接、对白、口型和连续性 | “将 @视频1 向后延长 5 秒……” |
| `aigc-vfx-combat` | 为国漫、仙侠、武侠战斗与法术提供阶段、形态、材质、物理反馈和机位设计；最终提示词交给图像或视频 Skill | “把这招普通火焰做成大制作级别的对轰设计” |
| `aigc-project-context` | 把剧本、分镜、镜头表和项目设定编译成镜头任务卡、连续性审计、表演理解和视频上下文 | “把这场戏整理成后续视频生成能直接接手的镜头卡” |
| `aigc-prompt-rewrite` | 清理已有提示词的语言，同时保护锚点、数字、参数、镜头顺序和生产事实；不代替图像或视频最终提示词工作流 | “只改这段画面描述的自然语言，不做最终平台适配” |

可以直接用自然语言，不必记 Skill 名。关键任务也可以显式点名：

```text
用 $aigc-image 诊断这张图，然后给一版保守修图提示词。
用 $aigc-video 将 @视频1 向后延长 5 秒，人物保持原姿势，缓慢转头看向门口。
用 $aigc-vfx-combat 把“女子发射火焰”升级成一张大制作战斗特效设计卡。
用 $aigc-project-context 根据剧本和分镜整理这一场的镜头任务卡。
用 $aigc-prompt-rewrite 保留全部 @锚点和对白，把这段提示词改自然。
```

## 工作逻辑

### 图像

`aigc-image` 会先判断当前需要哪一种交付物：

- 根据文字 brief 直接写最终图像提示词；
- 诊断画面为什么弱；
- 反推或复刻参考图；
- 写图像编辑提示词；
- 按用户要求把诊断和修图串在同一轮完成。

存在可读图片时，它会先完成中性读图和事实锁定。多张参考图会分别指定人物、构图、场景、风格、动作或编辑目标等角色，未分配的属性不会被自动借用。

生成、反推或修图提示词默认把中文与英文放在两个独立代码块中；两版语义一致，提交模型时选择其中一版。提示词采用“最小充分”原则：单一局部修改通常只写直接指令、必要重建和关键保持项，只有多参考图、精确文字或复杂版式才展开结构。平台适配覆盖 GPT Image 2、Nano Banana 系列与 Seedream 5.0 Pro；界面有独立控件时，比例、分辨率、质量等设置不混入视觉提示词正文。

### 视频

`aigc-video` 同时负责创作表达、生产约束和平台执行结构。它会先锁定素材角色、动作顺序、时长、对白、镜头关系和必要终态，再生成一个统一的视频运动规格，所有平台版本或 A/B 版本都从同一组事实派生。

Seedance 新生成或参考生成在总时长明确后，统一使用 `镜头N（开始-结束秒）：景别。` 加自然可执行的画面描述；时间段从 0 开始、连续不重叠并准确结束于总时长，默认采用整数秒。总时长缺失时先询问，不自行编造。只有粗白模已经提供完整切镜但具体切点不可读时，保留原镜头顺序与切镜，使用不带虚构秒数的 `镜头N：`。

当人物关系、站位、遮挡或必要环境状态必须从图像、分镜或视频中读取时，先输出镜头结构确认；文字已经完整给出共享构图时，同轮输出结构回显和最终提示词。两种表格都保留 `环境动态确认`，简洁说明风、雾、水、衣物、植被、光影及特效影响之间真实可见的因果关系。动态世界分析会扫描前中后景，但只激活画面中存在、可见且因果相关的元素，并跨镜继承已有风向、运动相位、扰动和余波。

音频、音乐、字幕和环境声只在用户、可用素材或项目明确提供时进入提示词。对白和口型任务会保留原文、说话人和可见口型条件。表演优先使用身体、视线、呼吸、表情、距离或物体接触等可见载体，不用空泛情绪词代替动作。

### 战斗与特效

`aigc-vfx-combat` 负责最终提示词之前的视觉设计层。它先判断场面是常规演出还是大制作节点，再用阵营色与形根统一招式识别，以“蓄力 → 爆发 → 余波”组织节拍，并补足环境、人物和空气中的物理反馈。

该 Skill 不单独输出 Seedance 或图像平台最终提示词：视频结果继续交给 `aigc-video`，静帧结果继续交给 `aigc-image`。这样既保留战斗特效的结构、材质和机位设计，也不跳过最终交付 Skill 的素材锁、平台语法和验证流程。

### 项目上下文

`aigc-project-context` 按字段判断剧本、分镜、用户指令和项目资产的权威性，输出带来源状态的镜头任务卡或连续性审计。需要最终视频提示词时，它会编译轻量视频上下文交给 `aigc-video`，不会要求用户手动完成两次相同的信息整理。

损坏、加密或当前环境不支持的必要素材不会被当作可读证据；受影响字段会保持待定，并请求可读导出文件或相关原文片段。

### 提示词改写

`aigc-prompt-rewrite` 只修改已有提示词的可变语言：删除模板腔和参数堆叠，补清主体、动作、空间与顺序。它不会修改 `@锚点`、对白、时长、时间码、镜头顺序、动作顺序、结尾状态或平台必要语法，也不会作为所有图像和视频提示词的强制末次改写。

## 提问与风险处理

Agent 只在答案会实质改变结果时打断用户：

- 缺少必要素材或不可见的边界状态时，请求素材或精确描述；
- 两个硬性要求无法同时成立时，解释冲突、给出建议并询问保留哪一项；
- 两种创作理解都有充分依据且会产生不同表演、构图或结尾时，说明当前理解、主要替代方案和推荐方向；
- 方案可执行但明显过载或不稳定时，先压缩可变内容并说明风险；
- 请求违反平台硬限制时，不输出一个看似可执行的无效命令，而是给出符合限制的替代路径。

已有上下文足够时直接继续；格式、普通措辞和不影响创作结果的技术细节由 Agent 自行处理。

## 个人默认值

除非当前任务、项目或素材另有明确要求：

- 交流、视频与普通文本默认中文；`aigc-image` 的生成、反推和修图提示词默认提供中英文两个独立版本；
- 最终视频平台默认按 Seedance 兼容结构处理；
- 默认不额外添加配乐、字幕、环境声或动作音效；
- 用户、素材或项目提供的音频、对白、静音和口型要求会保留；
- 表演偏克制，以一个主要可见载体承接情绪；
- 当前用户指令始终高于项目默认和个人默认。

这些是可覆盖的个人习惯，不会被伪装成平台硬规则。

## 安装到 macOS Codex

```bash
git clone git@github.com:Wanrd0Geri/aigc-codex-skills.git
cd aigc-codex-skills
chmod +x scripts/link-skills.sh
./scripts/link-skills.sh --force
```

脚本会按上表顺序确认五个 Skill 文件完整，再建立或更新链接。已有同名真实目录只会在 `--force` 下备份后替换。完成后重启 Codex。

## 安装到 Windows Codex

```powershell
git clone https://github.com/Wanrd0Geri/aigc-codex-skills.git
cd aigc-codex-skills
.\scripts\link-skills.ps1 -Force
```

PowerShell 脚本同样按相同顺序安装并验证这五个 Skill，处理冲突时遵循相同的备份和替换规则。完成后重启 Codex。

## 验证

带有 `test-prompts.json` 的 Skills 可用其中的用例检查触发边界、事实锁、素材状态和交付所有权。带 `requires: ["readable_source_image"]` 的用例必须由测试运行者注入真实可读图片，不能当作纯文本测试。测试文件不是自动打分器，也不代替你的成片判断。
