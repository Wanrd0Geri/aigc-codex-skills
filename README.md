# AIGC Codex Skills

这是一套按实际创作交付物组织的个人 AIGC Skills，包含图像编辑、视频、战斗特效设计和项目上下文四个互补入口。Agent 会根据用户真正需要的交付物选择工作流，保护素材事实和生产约束，并在关键创作判断不确定时主动讨论。

## 四个 Skills

| Skill | 它负责什么 | 典型说法 |
|---|---|---|
| `aigc-image` | 诊断可读图片，编写源图忠实的图像编辑提示词，执行修图，或清理已有图像编辑提示词的语言 | “诊断这张图并给 Nano Banana 一版保守修图提示词” |
| `aigc-video` | 编写或清理 Seedance、豆包、Dreamina 系列及平台中立最终视频提示词，覆盖生成、编辑、延长、桥接、对白、口型和连续性 | “将 视频1 向后延长 5 秒……” |
| `aigc-vfx-combat` | 为国漫、仙侠、武侠战斗与法术设计可读攻防、张力、物理反馈和可选特效；最终视频提示词交给 `aigc-video` | “把这段对攻设计得更有张力和重量” |
| `aigc-project-context` | 从当前项目源解析字段权威性，编译 ImageContext、VideoContext、镜头卡或连续性审计 | “读取当前分镜源，整理这场戏的视频上下文” |

可以直接用自然语言，不必记 Skill 名。关键任务也可以显式点名：

```text
用 $aigc-image 诊断这张图，然后给一版保守修图提示词。
用 $aigc-video 将 视频1 向后延长 5 秒，人物保持原姿势，缓慢转头看向门口。
用 $aigc-vfx-combat 把“女子发射火焰”升级成一张大制作战斗特效设计卡。
用 $aigc-project-context 根据剧本和分镜整理这一场的镜头任务卡。
```

## 工作逻辑

### 图像

`aigc-image` 会先判断当前需要哪一种图像编辑交付物：

- 诊断画面为什么弱；
- 写图像编辑提示词；
- 直接执行图像编辑；
- 在不改变生产事实的前提下，清理已有图像编辑提示词的语言。

涉及源图事实时，它会先确认图片可读，再完成中性读图和事实锁定。多张参考图会分别指定身份、场景、构图、材质、色彩或编辑目标等角色，未分配的属性不会被自动借用。纯语言清理只有在措辞依赖不可见像素时才需要源图。

默认只提供一份与用户语言一致的提示词；只有用户要求时才补充独立英文语义镜像。提示词采用“最小充分”原则：单一局部修改通常只写直接指令、必要重建和关键保持项，只有多参考图、精确文字或复杂版式才展开结构。平台适配覆盖 GPT Image 2、Nano Banana 系列与 Seedream 5.0 Pro；界面有独立控件时，比例、分辨率、质量等设置不混入视觉提示词正文。纯文字生图、参考图反推和 Midjourney 参数提示词交给对应专用工作流。

### 视频

`aigc-video` 同时负责创作表达、生产约束和平台执行结构。它会先锁定素材角色、动作顺序、时长、对白、镜头关系和必要终态，再生成一个统一的视频运动规格，所有平台版本或 A/B 版本都从同一组事实派生。

Seedance 新生成或参考生成在总时长明确后，统一使用 `镜头N（开始-结束秒）：景别。` 加自然可执行的画面描述；时间段从 0 开始、连续不重叠并准确结束于总时长，默认采用整数秒。总时长缺失时先询问，不自行编造。只有粗白模已经提供完整切镜但具体切点不可读时，保留原镜头顺序与切镜，使用不带虚构秒数的 `镜头N：`。

所有新生成、参考生成、结构重建、延长或桥接片段默认先进入结构确认；只有当前用户明确要求跳过确认时才直接编译最终提示词。确认表只保留构图机位、人物空间、动作对白终点、简短表演意图以及光线环境连续性。动态世界在内部逐镜审查，只有真实存在、可见且会改变结果的因果反应才进入最终提示词。

音频、音乐、字幕和环境声按平台规则、用户要求及可用素材分配。对白和口型任务会保留原文、说话人和可见口型条件。重要表演会把人物目的、观察到的反馈和有依据的策略变化写成可执行的自然语言，而不是只在内部分析或堆叠表情动作。

### 战斗与特效

`aigc-vfx-combat` 负责最终提示词之前的战斗设计层。它先建立可读威胁、速度反差、接触后果和攻守权变化，再决定是否需要特效；特效是强化动作证据的可选层，不代替战斗逻辑。

最终视频任务会先把战斗结构交给 `aigc-video` 完成统一结构确认，再补充演出、可选特效和可行性，最后由 `aigc-video` 输出平台提示词。设计卡任务可以在本 Skill 结束，但不会被伪装成 Seedance 最终提示词。

### 项目上下文

`aigc-project-context` 按字段判断用户指令、当前实时记录、本地当前源、有效缓存和已批准快照的权威性，输出带来源状态的 ImageContext、VideoContext、镜头卡或连续性审计。需要最终媒体提示词时，它只交接当前任务需要的最小上下文，不要求用户重复整理。

项目文件、生产附件、缓存和快照保存在 Skill 之外，避免工作流升级覆盖生产数据。损坏、加密、过期或当前环境不支持的必要素材不会被当作当前证据；受影响字段会保持待定，并请求可读来源。

## 提问与风险处理

Agent 只在答案会实质改变结果时打断用户：

- 缺少必要素材或不可见的边界状态时，请求素材或精确描述；
- 两个硬性要求无法同时成立时，解释冲突、给出建议并询问保留哪一项；
- 两种创作理解都有充分依据且会产生不同表演、构图或结尾时，说明当前理解、主要替代方案和推荐方向；
- 方案可执行但明显过载或不稳定时，先压缩可变内容并说明风险；
- 请求违反平台硬限制时，不输出一个看似可执行的无效命令，而是给出符合限制的替代路径。

已有上下文足够时直接继续；格式、普通措辞和不影响创作结果的技术细节由 Agent 自行处理。

## 个人默认值

除非当前任务、项目或素材另有明确要求：

- 交流与视频默认中文；`aigc-image` 默认只输出一份用户语言版本，英文语义镜像仅在用户要求时提供；
- 最终视频平台默认按 Seedance 兼容结构处理；
- 默认不额外添加配乐、字幕、环境声或动作音效；
- 用户、素材或项目提供的音频、对白、静音和口型要求会保留；
- 表演偏克制，以一个主要可见载体承接情绪；
- 当前用户指令始终高于项目默认和个人默认。

这些是可覆盖的个人习惯，不会被伪装成平台硬规则。

## 安装到 macOS Codex

```bash
git clone git@github.com:Wanrd0Geri/aigc-codex-skills.git
cd aigc-codex-skills
chmod +x scripts/link-skills.sh
./scripts/link-skills.sh --force
```

脚本会按上表顺序确认四个 Skill 文件完整，再建立或更新链接。已有同名真实目录只会在 `--force` 下备份后替换；已退役的 `aigc-prompt-rewrite` 会按同样的安全规则移除链接或备份真实目录。完成后重启 Codex。

## 安装到 Windows Codex

```powershell
git clone https://github.com/Wanrd0Geri/aigc-codex-skills.git
cd aigc-codex-skills
.\scripts\link-skills.ps1 -Force
```

PowerShell 脚本同样按相同顺序安装并验证这四个 Skill，处理冲突和退役 Skill 时遵循相同的备份与替换规则。完成后重启 Codex。

## 验证

带有 `test-prompts.json` 的 Skills 可用其中的用例检查触发边界、事实锁、素材状态和交付所有权。带 `requires: ["readable_source_image"]` 的用例必须由测试运行者注入真实可读图片，不能当作纯文本测试。测试文件不是自动打分器，也不代替你的成片判断。
